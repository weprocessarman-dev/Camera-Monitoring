# WeSurveil - Camera Monitoring Website

Professional camera monitoring and security solutions built with Next.js.

## Features
- 24/7 monitoring services
- AI-powered threat detection
- Real-time alerts
- Professional verification
- EmailJS contact form integration
- Responsive design

## Deployment
Automatically deploys to Namecheap hosting via GitHub Actions on push to master branch.

## Tech Stack
- Next.js 14
- Tailwind CSS
- Framer Motion
- EmailJS
- React Icons
